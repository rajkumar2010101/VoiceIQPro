📖 How API Connections Work
What is an API connection?

An API connection lets VoiceIQ Pro automatically pull data from your existing tools (Five9, Salesforce, Zendesk etc.) instead of you manually uploading CSVs. Once connected, conversations flow in automatically in real-time.

What you need from your CRM

1. API Key — from your CRM's admin settings
2. Endpoint URL — the data export or webhook URL
3. Field mapping — which field in your CRM = customer_message

📥 Push Data INTO VoiceIQ — Ingest API

Your contact center can also push individual conversations to VoiceIQ in real-time using a simple POST request. This works for any platform that supports webhooks or HTTP callbacks.

Endpoint: POST {{ request.host_url }}api/ingest
curl -X POST {{ request.host_url }}api/ingest \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{
    "customer_message": "My refund has not arrived in 3 weeks!",
    "agent": "Agent_Priya",
    "channel": "Phone",
    "date": "2024-03-15"
  }'
Response:
{"sentiment":"negative","emotion":"frustrated","topic":"Refund Delay",
"escalation_level":"HIGH","escalation_score":72,"status":"analyzed"}
